# Numerical Methods Toolkit

An interactive Python application for exploring, visualizing, and comparing classical numerical methods.

## Implemented Methods

### Root Finding
- Newton Method
- Relaxation Method

### Linear Systems
- Gaussian Elimination with Partial Pivoting
- Successive Over-Relaxation (SOR)
- Residual analysis
- Condition number and determinant calculation

### Interpolation
- Lagrange Interpolation
- Hermite Interpolation
- Linear Splines
- Cubic Splines
- Numerical error comparison

## Key Features

- Interactive desktop interface
- Convergence visualization
- Residual analysis
- Interpolation comparison
- Numerical error evaluation
- Adjustable algorithm parameters
- Graphical presentation of computational results

## Technologies

Python · NumPy · SciPy · Matplotlib · Tkinter · Numerical Analysis
