# Graph Algorithm Visualizer
An interactive desktop application for visualizing and exploring classic graph algorithms step by step.
The project demonstrates practical implementations of fundamental graph algorithms together with an interactive graphical interface that makes their execution easier to understand and compare.

## Algorithms
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Dijkstra's Shortest Path Algorithm
- A* Search Algorithm
- Prim's Minimum Spanning Tree
- Ford-Fulkerson Maximum Flow

## Features
- Step-by-step algorithm execution
- Automatic animation mode
- Interactive start and target vertex selection
- Weighted graph visualization
- Shortest path visualization
- Minimum spanning tree construction
- Maximum flow visualization
- Edge weights and network capacities
- Execution status and algorithm results

## Technologies
- Python
- Tkinter
- Matplotlib
- Graph Theory
- Data Structures and Algorithms

## Purpose
This project was developed to explore the implementation and visualization of fundamental graph algorithms and to demonstrate practical algorithmic problem-solving using Python.

## Run Locally
Install the required dependency:

`pip install matplotlib`

Run the application:

`python graph_algorithms.py`
